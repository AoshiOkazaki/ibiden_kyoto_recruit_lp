# イビデン 京都エリア向け採用広報サイト

## ページ

https://aoshiokazaki.github.io/ibiden_kyoto_recruit_lp/

## リポジトリ

https://github.com/AoshiOkazaki/ibiden_kyoto_recruit_lp

## 概要

イビデンの技術力と、京都で暮らしながら岐阜で働く選択肢を紹介する採用広報サイトのプロトタイプです。

ICパッケージ基板がスマートフォン、AI・データセンター、自動車、ウェアラブルなどの先端機器を支えていることや、イビデン独自の微細配線技術・マイクロビア技術を紹介しています。また、給与・家賃・社宅費・通勤費などを比較できる手取りシミュレーターと、京都から岐阜への通勤ルート、社員の声、説明会・工場見学への導線を掲載しています。

## 主な内容

- ICパッケージ基板とイビデンの技術紹介
- 超微細配線を可能にする導体形成技術の紹介
- 接続信頼性の高いマイクロビアの紹介
- 京都での暮らしと岐阜での勤務を比較する手取りシミュレーター
- 京都から岐阜への通勤ルート紹介
- 社員の声と採用イベントへの案内

## 使用技術

- HTML
- CSS
- JavaScript

## ファイル構成

- `index.html`：ページの構造とコンテンツ
- `styles.css`：レイアウト、配色、レスポンシブ対応
- `script.js`：手取りシミュレーターの計算とダイアログ操作
